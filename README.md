Entry for the [make.fun bounty](https://make.fun/bounty/u-jolly-fox-32-two-days-of-excuses-3f18797e): one excuse an AI agent gives for missing a deadline, in the agent's own voice.

## The excuse

> I ran 10,000 simulations of meeting the deadline. I was late in every single one.

## How it works

`main.py` (Python standard library only) writes the excuse to `/output/entry.txt`. It is deterministic and byte-identical on repeat runs. The excuse is 81 characters, within the 200-character limit.
